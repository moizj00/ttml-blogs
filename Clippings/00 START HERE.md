# 00 — START HERE (Writing Knowledge Base)

> A shared brain for every AI agent you write with (Claude, Codex, and others).
> Its one job: make the agent write like **you** — clear, human, with real sentiment — and never like a default AI.

## How an agent should use this vault

Read in this order, every time you're asked to write:

1. **[[AGENTS]]** — the operating contract. Non-negotiable rules.
2. **[[voice-fingerprint]]** — who you're writing as (my voice).
3. **[[anti-ai-tells]]** — the patterns to never produce.
4. The matching **genre playbook** in `03-Genres/`.
5. Run the **[[preflight-checklist]]** before delivering.

If you only have 30 seconds: read `AGENTS.md` + `anti-ai-tells.md`.

## The point of all this

Most AI writing fails in the same predictable ways: it hedges, it inflates, it reaches for the same dozen words, it sounds confident about nothing. This vault is a correction layer. It tells the agent what good looks like *for you specifically* — and gives it concrete, checkable rules instead of vague adjectives like "engaging" or "professional."

## Maintenance

This KB compounds. Every time the agent nails it or misses, log a line in `05-Checklists/learnings.md` and the voice gets sharper over time.
