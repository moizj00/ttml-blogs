# Samples — feed your voice in here

This folder is the fuel for [[voice-fingerprint]]. The agent learns your voice from real writing, not adjectives.

## What to add (3–5 pieces is enough to start; more is better)
- Pick things **you actually wrote** and were happy with.
- Spread across formats you care about: an essay or long email, a couple of social posts, anything narrative/personal.
- Raw is fine — typos and all. Don't clean them up; the imperfections are signal.

## How to add them
- Drop each as its own `.md` file here. Name them by type, e.g. `essay-on-x.md`, `linkedin-post-1.md`, `personal-email.md`.
- One file per piece keeps extraction clean.

## Optional but powerful: anti-samples
Create a file `_anti-samples.md` with writing you **hate** (generic AI output, corporate fluff). Telling the agent what to avoid is as useful as what to copy.

## Then
Ask: *"Extract my voice fingerprint from my samples and update voice-fingerprint.md with real evidence."*

---
*This folder is empty until you add to it. The rest of the KB works without samples, but voice matching only gets great once these exist.*
