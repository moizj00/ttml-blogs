# Word Bank — Swaps, Bans, and Keepers

A quick lookup for word choice. Pair with [[anti-ai-tells]] (section B) and [[mechanics]].

## Banned (AI word-cloud — avoid)
delve · tapestry · testament · realm · landscape (figurative) · navigate (figurative) · unlock · unleash · elevate · leverage (verb) · robust · seamless · streamline · game-changer · cutting-edge · best-in-class · world-class · boasts · nestled · bustling · vibrant · embark · journey (figurative) · foster · harness · pivotal · crucial · vital · myriad · plethora · treasure trove · beacon · cornerstone · paramount · underscore · holistic · synergy · ecosystem (non-tech) · curated · meticulous · profound(ly) · ever-evolving · fast-paced

## Filler to cut (almost always)
very · really · quite · just · actually · simply · basically · literally · truly · deeply · highly · extremely · incredibly · in order to · the fact that · there is / there are · it is important to note · needless to say · at the end of the day

## Plain-English swaps
| Instead of | Use |
|---|---|
| utilize | use |
| facilitate | help |
| demonstrate | show |
| regarding / in regards to | about |
| in order to | to |
| a large number of | many |
| at this point in time | now |
| due to the fact that | because |
| terminate | end |
| commence | start |
| endeavor | try |
| in the event that | if |
| prior to | before |
| subsequent to | after |
| with the exception of | except |

## Corporate-speak to kill
circle back · touch base · leverage synergies · move the needle · low-hanging fruit · boil the ocean · bandwidth · take this offline · drill down · ping me · per my last email · think outside the box

## Keepers (plain words that earn their place)
but · so · and yet · still · because · the trouble is · here's the thing it actually replaces (use a real point) · enough · most · few

> Rule of thumb: if you wouldn't say the word out loud to a smart friend, don't write it.
