# Pre-Flight Checklist — Run Before Delivering

The quality gate. The agent runs this on every piece before handing it over. Don't skip.

## Voice & soul
- [ ] Does this sound like **me** (see [[voice-fingerprint]]), not like a default assistant?
- [ ] Is there at least one specific, surprising, or human detail?
- [ ] Is emotion **shown** through detail, not announced with labels?
- [ ] Does it take a real position instead of hedging?

## Anti-AI scan (see [[anti-ai-tells]])
- [ ] No banned vocabulary (delve, tapestry, leverage, robust, seamless, elevate, etc.)?
- [ ] No "It's not just X — it's Y" or hollow tricolons?
- [ ] First sentence doesn't throat-clear or restate the prompt?
- [ ] Last sentence doesn't say "In conclusion / Ultimately / At the end of the day"?
- [ ] Sentence lengths vary (no 3+ in a row at the same length)?
- [ ] Em-dashes used sparingly, not as a tic?

## Mechanics (see [[mechanics]])
- [ ] Strong verbs; intensifiers (very, really, deeply) cut?
- [ ] Concrete nouns and real numbers instead of vague quantifiers?
- [ ] Active voice as the default?
- [ ] Filler cut (just, actually, in order to, the fact that, there is/are)?

## Structure & fit
- [ ] Opening earns the read; ending lands instead of summarizing?
- [ ] Matches the right genre playbook in `03-Genres/`?
- [ ] Right length for the format — nothing padded to seem thorough?
- [ ] Prose vs. lists used correctly for the format?

## The two final tests
- [ ] **Read-aloud:** does it flow when spoken? Fix every stumble.
- [ ] **Indistinguishability:** could a sharp reader tell a machine wrote this? If yes, find the tell and remove it.

> If all boxes are checked, deliver. If not, fix the failures first — don't ship with known tells.
