# Foundation-10 — The Canon

> The 10 articles every blog-writing agent studies before drafting. This is the **quality bar** and the **voice source** for TTML blog content.
> Mix of two kinds: **famous exemplars** (craft to learn from — stored as link + deep breakdown) and **our own best pieces** (stored as full text + notes, the truest voice signal).

## How an agent uses this folder
Before writing a TTML blog post:
1. Read [[voice-fingerprint]] and [[AGENTS]].
2. Read the 2–3 Foundation entries closest to the task (e.g. a legal explainer + a persuasive-craft piece).
3. Steal *moves*, not words: the hook style, the structure, the way it handles the reader. Then write in our voice.

## Storage rule (copyright-safe)
- **Our own pieces:** full text + notes. ✅
- **Famous/3rd-party articles:** link + annotated breakdown only — no full copyrighted text pasted. The breakdown captures everything an agent needs.
