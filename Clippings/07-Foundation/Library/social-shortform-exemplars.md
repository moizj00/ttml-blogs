# Catalog: Social & Short-Form Exemplars (~12)

For TTML's distribution: X, LinkedIn, and the hooks that pull readers into the blog. Study the *hook and compression*, not the follower counts.

## Accounts / writers worth studying
1. ⭐ **Naval Ravikant — "How to Get Rich (without getting lucky)" tweetstorm** — https://nav.al/rich ✅ — *A whole philosophy as standalone one-liners. Each tweet survives alone.*
2. **Naval — aphorism style** (twitter.com/naval) 🔎 — *Compress a big idea to a line you can't forget. Density = shareability.*
3. ⭐ **Sahil Bloom — explainer threads** 🔎 — *Hook → numbered insights → recap. The teachable-thread template.*
4. **Shaan Puri — story threads** 🔎 — *Open mid-story; the first line creates a gap you must close.*
5. **Justin Welsh — LinkedIn** 🔎 — *One lesson, one short story, one CTA. Repeatable without feeling templated.*
6. **Dickie Bush / Ship30for30** 🔎 — *Atomic essays: one idea, screenshot-sized, a strong "so what."*
7. **Katelyn Bourgoin — marketing threads** 🔎 — *Voice-of-customer hooks; lead with the reader's exact words.*
8. ⭐ **Nikita Bier — product/launch posts** 🔎 — *Punchy, contrarian, zero throat-clearing. Master of the first line.*

## Pattern references (not accounts)
9. **The "I did X for N days, here's what happened" hook** 🔎 — *Specific number + curiosity gap. Overused but works when the result is real.*
10. **The reversal hook** ("Everyone says X. They're wrong.") 🔎 — *Tension in line one. Earn it or it's clickbait.*
11. **The confession hook** ("I almost killed the project...") 🔎 — *Vulnerability buys attention; pay it off with a real lesson.*
12. **The single-number proof post** ("Got 0 to 40k users. One thing mattered.") 🔎 — *Concrete result up front, one takeaway, stop early.*

## TTML application
- Turn each blog post into 2–3 social hooks using these patterns (e.g. "Your landlord can't actually do this in California. Here's the letter that proves it.").
- Match the platform: terse on X, story-with-a-lesson on LinkedIn. See [[social-shortform]].
- Never use the dead tells: "Let that sink in," "a thread 🧵," hashtag walls. See [[anti-ai-tells]].
