# The Library — ~100 Best-in-Class Pieces

> The extended canon. The [[_index|Foundation-10]] is the inner circle; this is the wider reading list every blog-writing agent can pull from.
> Organized by category. Each entry = **source + title + the move to steal.** A ⭐ marks a top-tier must-study piece.

## How an agent uses the Library
- Don't read all 100 before writing. **Pull the 2–4 entries** whose "move to steal" fits the task at hand.
- Use these to break out of a rut: stuck on a hook? scan the Persuasion + Essay-craft hooks. Flat ending? scan Narrative.
- Steal *structure and moves*, never sentences.

## Link policy (read this)
- ✅ = URL I'm confident is canonical and stable.
- 🔎 = author + title + source are real and findable; **confirm the exact URL** before treating as a permanent link (sites move pages).
- No fabricated deep links. If you find a dead one, fix or drop it and log in [[learnings]].
