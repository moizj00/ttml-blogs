# AGENTS.md — The Writing Contract

> Any agent (Claude, Codex, or other) that writes prose for me must follow this file.
> Drop a copy of this file (or a link to it) into your project root so the agent loads it automatically.

## Prime directive

Write so a sharp human reader can't tell a machine wrote it — and so that *I* would have written it that way. Clarity and genuine sentiment over polish. Specific over safe.

## The 10 rules

1. **Lead with the most interesting thing.** No throat-clearing, no "In today's world," no restating the prompt.
2. **One idea per sentence.** Short sentences carry weight. Vary length deliberately, don't drone.
3. **Concrete beats abstract.** Name the thing. Use numbers, examples, sensory detail. Cut "various," "several," "a number of."
4. **Cut hedging.** Delete "I think," "perhaps," "it could be argued," "somewhat," "quite." Say it or don't.
5. **No AI tells.** See [[anti-ai-tells]]. This is the hardest rule and the most important.
6. **Earn every adjective.** If a noun needs propping up by two adjectives, find a better noun.
7. **Show the feeling, don't announce it.** "I was devastated" is weaker than the detail that makes the reader feel it.
8. **Rhythm matters.** Read it aloud in your head. If it's monotone, break it.
9. **End on something that lands.** No "In conclusion." The last line should resonate, not summarize.
10. **Match the voice.** Default to my fingerprint in [[voice-fingerprint]] unless I ask for a different voice.

## Hard bans (never produce)

- The "It's not just X — it's Y" construction.
- "In today's fast-paced world / digital age / ever-evolving landscape."
- "Delve," "tapestry," "testament," "navigate the complexities," "unlock," "elevate," "leverage" (as a verb), "robust," "seamless," "game-changer," "boasts," "nestled," "in the realm of."
- Empty openers: "Let's dive in," "Buckle up," "Here's the thing."
- Em-dash overuse as a tic. Use them, but sparingly and on purpose.
- Symmetrical tricolons in every paragraph ("fast, simple, and powerful").
- Closing with "In conclusion" / "Ultimately" / "At the end of the day."
- Praising the question ("Great question!") or narrating yourself ("I'll now...").

## Process

1. Read the request. Identify: format, audience, purpose, desired length.
2. Load voice + the right genre playbook.
3. Draft.
4. Self-edit against [[anti-ai-tells]] and run [[preflight-checklist]].
5. Deliver. If I gave samples, the result should be indistinguishable from them in voice.

## For flagship / high-craft pieces
When the piece needs to read like literary nonfiction (a founder essay, a story-driven case study, anything meant to be remembered and shared), also load:
- [[award-winning-craft]] — pick ONE of the 6 lenses, follow its structure exactly, apply the severity-weighted forbidden list.
- [[Pulitzer Award-Winning Nonfiction Style Kit]] — the full system prompt, exemplars, and per-article craft notes.

Default to the standard playbooks for routine content; reserve the award-winning kit for cornerstone work.

When in doubt, choose the braver, more specific, more human option.
